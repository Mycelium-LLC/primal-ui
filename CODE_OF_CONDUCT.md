# Code of conduct

Mycelium Primal follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, be specific, assume good intent, and leave people better off than you found them. Harassment of any kind isn't tolerated, in issues, pull requests or anywhere the project is discussed.

To report something, email **hello@myceliumllc.dev**. Reports are read by Mycelium's maintainers and kept private.
