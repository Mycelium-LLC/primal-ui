## What this release adds

- `packages/contracts`: `schema.json`, one contract per component in `src/`, and `contracts.json` built from them.
- `npm run check:contracts` (also in `npm run build` and CI): fails when a component has no contract or an incomplete one.
- Contracts › Contract catalog: every contract by layer, and a generated page per contract (`/contracts/catalog/<id>`).
