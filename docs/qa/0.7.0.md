## What this release adds

- Content: cards only as list items, list items, details, the table's empty row, code blocks (Content › Content).
- Information: badges, status by shape, word and colour, avatars, empty states, and a without-colour switch (Content › Information).
- Layout: stack, inline, grid, container, divider, scroll area, toolbar, search field, and a strip-the-boxes switch (Content › Layout).
- Cells: subscribe, search with results, an item tile (Content › Cells).
