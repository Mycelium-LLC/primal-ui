## What this release adds

Five reference surfaces, each with its journey and next two moves written on its page (Surfaces in the menu):

| Surface | Its addresses |
|---|---|
| Authentication | `/surfaces/authentication/sign-in`, `/sign-up`, `/reset` |
| App shell | one page, the shell shown at a desk's width and a phone's |
| Settings | `/surfaces/settings/profile`, `/notifications`, `/appearance`, `/account` |
| List and detail | `/surfaces/list-detail`, `/surfaces/list-detail/<report-slug>` |
| Multi-step form | `/surfaces/multi-step-form?step=workspace`, `team`, `review` |

never finished there, which held the router. With transitions switched off the journeys pass (row 6). In a visible browser the
transitions finish on their own; please confirm by clicking through List and detail and the Multi-step form.
