# QA 0.1.0 — A base you can make your own

Mycelium Primal's first release: the foundation (tokens, colour from three choices, Google Sans, the reset and base
styles, light and dark, both text directions), the Angular adapter's first pieces, and the showcase with every planned
page. Folio plan: `.folio/ledger.json`, release 0.1.0. Niko reviewed it by eye on 2026-10-20 ("we good").

## Run it from a fresh clone

Needs Node 24 (`.nvmrc`).

```bash
git clone -b release/0.1.0 https://github.com/Mycelium-LLC/primal-ui.git primal-qa && cd primal-qa
npm ci
npm run check:folio    # ✔ ledger ok: 9 releases, 54 requirements at 1.0.0
npm run check:tokens   # ✔ tokens are up to date / ✔ contrast: 1760 pairs … / ✔ no literal values …
npm run build          # ✔ Built primal-angular, then "Application bundle generation complete"
npx ng serve showcase  # http://localhost:6840
```

Failing looks like: a ✖ line from any check (it names the token, pair or file), or an `✘ [ERROR]` from the build.

## Not in this release

- No packages are published; Primal is used from this repository (Getting started says so).
