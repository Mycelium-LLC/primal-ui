# QA 0.6.0 — You always know where you are

Draft, in progress. Folio plan: `.folio/ledger.json`, release 0.6.0. It builds on 0.5.0 (`release/0.5.0`), which contains 0.4.0
and 0.3.0; merge those first.

No QA run until Niko asks for one (decision 29). When he does, QA walks the two journeys in `docs/qa/0.5.0.md`: use Primal in a new
Angular project, and build your own design system on it.

## What this release adds

- Navigation: tabs, breadcrumbs, pagination, a menu, navigation items (Navigation › Navigation).
- Disclosure: accordions on `<details>`, one-open-at-a-time by name (Navigation › Disclosure).
- Dialogs: a short-task dialog, a confirmation (`PrimalConfirm`), a menu inside a dialog, and the seven top-layer answers
  (Navigation › Dialogs).
- Popovers and tooltips (Navigation › Popovers and tooltips).
- Focus and keys: the four rules and every component's keys (Navigation › Focus and keys).
