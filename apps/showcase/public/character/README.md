# The showcase's character

Mycelium's own character, in a few places of the showcase only. Primal's components carry none of it: Primal is the base every
design system is built from, so a product brings its own.

- The illustrations are Mycelium's, from its brand book (Mycelium-LLC/mycelium-personality, `public/art/sticker/`).
- Square Peg, the handwritten face of the brand book's notes, is under the SIL Open Font License (`SQUARE-PEG-OFL.txt`).
- The rules are the brand book's Mischief chapter: one surprise per screen, only in a welcome, an empty state or a success, never
  in a table, a form, an error or anything about money; notes of six words or fewer that carry no information; nothing moves.
