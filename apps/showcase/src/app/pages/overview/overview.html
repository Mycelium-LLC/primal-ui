Mycelium Primal

The open-source design system by Mycelium. Design from first principles.

You can use Primal as it is, and it's also the base every future Mycelium design system starts from, so its own look stays minimal and is set through tokens. Each element is a primitive, a cell or a surface, depending on the promise it keeps.

Primitive
Part of a promise that isn't a whole job yet: a label, a field, a button, a heading.
Cell
One complete, predictable job: a newsletter signup, a search with its results.
Surface
Where cells serve a journey: a sign-in page, a settings area.

What's here

Every planned page is already in the menu. A page not built yet shows the plain native HTML elements it will cover, and the release that builds it replaces it.
