Contract catalog

Every element in Primal says what it promises, what its presence makes someone expect, and how it shows it kept the promise; then its behaviour, context, relationships, states, accessibility and what it must never do. The contracts are data next to the code (packages/contracts), every page here is generated from them, and the build fails if any component is missing one.
