Getting started

Primal is two CSS files, the tokens and the core styles, plus an adapter for each framework. The CSS works on any web page. Angular is the first framework with an adapter.

Want a working app right away? Start from the starter, an Angular app with Primal set up: npx degit Mycelium-LLC/primal-ui/starter my-app.

1. Get the packages

Primal's packages are on GitHub Packages, under @mycelium-llc. GitHub Packages asks for a GitHub token even to install a public package, so first point the scope there in your project's .npmrc, and set GITHUB_TOKEN to a GitHub personal access token (classic) with the read:packages scope: 

{{ npmrc }}

Then, for an Angular project, install the tokens, the CSS and the adapter:

{{ install }}

Working on Primal itself, or trying a change before it's published? Pack it from a clone and install the files instead:

{{ build }}
@mycelium-llc/primal-tokens
Every token as a CSS custom property, with its light and dark values (primal-tokens.css).
@mycelium-llc/primal-css
The core styles (src/primal.css) and the Google Sans font files they load.
@mycelium-llc/primal-angular
The Angular adapter, for Angular 22 or later.
@mycelium-llc/primal-contracts
Every component's contract as JSON, with its schema, and primal-contracts-check to check your own when you build a design system on Primal: npx -p @mycelium-llc/primal-contracts primal-contracts-check path/to/contracts. It reads every .json file in that folder as a contract, so keep the folder for contracts only.

2. Load Primal

Load the tokens first, then the core styles, then your own theme file if you have one.

On any web page

{{ html }}

In Angular 22 or later

Add the files to your project's styles in angular.json:

{{ angularJson }}

Page changes cross-fade, timed by Primal's motion tokens and instant under reduced motion: add withPrimalTransitions() to your router. Then, so that moving to a new page starts at its top, add providePrimalRouteScroll() next to your router. Back and forward still return the person to where they were. If your pages scroll inside a box rather than the window (an app shell whose main area scrolls on its own), give it that box: providePrimalRouteScroll({ scroller: () => document.getElementById('main') }). 

{{ config }}

To switch light and dark, the text direction, or scrolling to the top, use PrimalPreferences from the adapter. Each setting writes one attribute on the page, and Primal's tokens respond to it. 

{{ prefs }}

3. Make it yours

Primal's look is plain on purpose: Mycelium's Magma on ink and white. Your colour is three choices, your black, your white and your primary, plus a harmony. Every colour role derives from them. Pick them on the Colour page, copy the file it writes, and load it after Primal. Any other token can be overridden the same way. You never edit a component. 

{{ theme }}

Every token, its value and its meaning are under Foundation. Read the meaning before you override a token: a token keeps its meaning in every theme.
