Getting started

Primal is two CSS files, the tokens and the core styles, plus an adapter for each framework. The CSS works on any web page. Angular is the first framework with an adapter.

Primal isn't published to a package registry yet, so you use it from its repository, Mycelium-LLC/primal-ui, which is private for now.

1. Get the files

Clone the repository and build it. This needs Node 24.

{{ build }}
packages/tokens/primal-tokens.css
Every token as a CSS custom property, with its light and dark values.
packages/css/src/
The core styles (primal.css) and the Google Sans font files they load. Keep the folder together.
dist/primal-angular
The Angular adapter, produced by the build.

2. Load Primal

Load the tokens first, then the core styles, then your own theme file if you have one.

On any web page

{{ html }}

In Angular 22 or later

Add the files to your project's styles in angular.json:

{{ angularJson }}

So that moving to a new page starts at its top, add providePrimalRouteScroll() next to your router. Back and forward still return the person to where they were. 

{{ config }}

To switch light and dark, the text direction, or scrolling to the top, use PrimalPreferences from the adapter. Each setting writes one attribute on the page, and Primal's tokens respond to it. 

{{ prefs }}

3. Make it yours

Primal's look is plain on purpose. Override any token in your own file, loaded after Primal's, and every element follows. You never edit a component. Colours take a light and a dark value. 

{{ theme }}

Every token, its value and its meaning are under Foundation. Read the meaning before you override a token: a token keeps its meaning in every theme.
