Select

A select is one answer from a list that is too long for radios. Primal draws the list: it opens under the field, as wide as it, and answers the keys a native select does (the arrows, Home and End, typing a letter to jump, Enter to choose, Escape to close). The native select stays inside as the value, so forms, required and reset work as they always do.

One from a list

Grouped options

Options that belong together sit under a heading. One that can't be chosen now stays in the list, stepped back.

States

Several from a list

When the person can choose more than one, the list stays open in the page, so they see everything they've chosen.

Autocomplete

When the person knows the answer, they type it. Clicking the field shows every option first; typing narrows them to the ones that contain the text, with the match marked. The arrows and Enter choose, and Escape closes the list, or clears the field.
