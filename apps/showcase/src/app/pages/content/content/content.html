Content

Content parts show things as what they are. A card is one of a collection you open; a list item is one row of a list; details are facts about one thing; a table is for reading across and down; a code block is code to read and copy.

Cards

A card is a list item: one of several, each something you open. So Primal draws a card only inside a list of cards, and the whole card is the target. A lone card, or a card around a page, gets no card treatment at all.

    @for (r of reports; track r.title) {

  • {{ r.title }}

    {{ r.summary }}

    {{ r.stateLabel }} Updated {{ r.updated }}

    • }

Narrow a card and its "Updated" line gives way first; the title and summary stay, and wrap, never cut.

List items

One row each: who or what, a line about it, and its state or action at the end.

    @for (p of people; track p.name) {
  • {{ p.name }} {{ p.email }} {{ p.stateLabel }}
    • }

Details

Facts about one thing, each a term and its value: side by side where there's room, one under the other on a phone.
