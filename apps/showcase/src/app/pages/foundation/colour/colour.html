Colour

Each colour is a role with one meaning. It is never picked for how it looks in one place. There is one accent, and it means "something happens here". The other roles are quiet, so that whatever needs attention can lead.

Each role has a value for light and dark. Every text and control pair is checked against WCAG 2.2 AA on every build.
