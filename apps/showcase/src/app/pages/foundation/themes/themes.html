Themes

Primal looks plain on purpose. It's the base that other design systems start from, so it carries no brand, and what you see here is exactly what a project gets when it imports Primal. A project gets its own look by overriding tokens in one file of its own, and no component changes.

Light and dark

Light and dark are the same base, with each colour role given a value for both. The base follows the system, and the Theme switch in the header forces one. data-theme="light" or "dark" also forces one on any element, so a single region can differ from the page:

Making a theme

For colour, a project sets three choices (its black, its white and its primary) and a harmony, and every colour role follows, in light and dark. Pick them on the Colour page and copy the file it writes.
