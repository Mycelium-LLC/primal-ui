Every element keeps a promise

Each of Primal's 53 parts has a contract: what it promises, its states, its keys, its accessibility and the markup to copy. The contracts are plain JSON, framework-free, and a checker keeps your own just as complete.

Install Primal

Use it as it is, in a new or existing Angular 22 project.

The packages are on GitHub Packages, which asks for a GitHub token with read:packages even to install, in GITHUB_TOKEN. Point the scope there in your .npmrc:

@mycelium-llc:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}

Then install:

npm install @mycelium-llc/primal-tokens @mycelium-llc/primal-css @mycelium-llc/primal-angular

Then load the styles in angular.json, tokens first:

"styles": [
  "node_modules/@mycelium-llc/primal-tokens/primal-tokens.css",
  "node_modules/@mycelium-llc/primal-css/src/primal.css"
]

Not on Angular? The two CSS packages work on any web page. Read Getting Started

Fork Primal

Make it the base of your own design system: your name, your colour, your contracts.

  1. Make your copy with Use this template on GitHub.
  2. Set your three colours on the Colour page and save its file.
  3. Write your contracts and check them: npx -p @mycelium-llc/primal-contracts primal-contracts-check contracts/
